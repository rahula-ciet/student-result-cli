# Student Result Processing CLI

## Project Description

This project is a modular command-line application developed using Go.

The application accepts student details and marks, then calculates:
- Total marks
- Average marks
- Grade
- Pass/Fail status

## Technologies Used

- Go 1.27.1
- Visual Studio Code
- Git
- GitHub
